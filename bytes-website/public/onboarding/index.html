Where do I paste it?
  • WordPress: Appearance → Theme File Editor → footer.php, before </body> (or use a “header and footer scripts” plugin).
  • Shopify: Online Store → Themes → Edit code → theme.liquid, before </body>.
  • Wix: Settings → Custom code → Add custom code → Body – end, all pages.
  • Squarespace: Settings → Advanced → Code injection → Footer.
  • Webflow: Site settings → Custom code → Footer code, then publish.
